Software

Roommate Chore Chart

Developed a website, hosted on Vercel, connected to a SQL database hosted on Supabase, to manage a house chore chart. Chores and chore assignments automatically shuffle every Monday, adjusting based on whether the house is at max capacity (9 roommates) or summer capacity (6 roommates). The website includes a check-off feature so roommates can visually track which chores have been completed.
On the backend, the SQL database enforces two rules: only residents of a given floor are assigned to clean that floor's bathroom, and no roommate is assigned both a common-area chore and a bathroom chore in the same week. Claude was utilized to assist with the web development and the conversion of a Python algorithm I had written for chore assignment into SQL logic for the database.
